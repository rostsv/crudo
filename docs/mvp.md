# MVP Scope

## Must Have
| Feature | Notes |
|---|---|
| Onboarding | Welcome → pain screens → preferences → meal count → first meal setup → paywall |
| Authentication | Email + password, Google, Apple, Facebook |
| Free trial + paywall | ~7 days trial, monthly + annual subscription |
| One active nutrition plan | Repeats daily by default |
| Multiple plans assignable by day | Mon = Plan A, Tue = Plan B, etc. |
| Meal slots | Pre-created based on meal count from onboarding |
| Meal tags | Breakfast / Lunch / Dinner / Snack / Pre-workout / Post-workout (multiple) |
| Reusable meals | Same meal can be used across multiple plans |
| Meal blocks with ingredients + grams | User-defined, all quantities in grams |
| Built-in starter food list | Bundled with app, no API |
| Custom food creation | Name, protein/carbs/fats required, calories auto-calculated with 10% validation |
| Today screen | Streak, calories consumed vs planned, meals completed, meal list with status |
| Meal detail view | Ingredient checklist + Done / Partial / Skip / Snooze actions |
| Meal marking | Per ingredient yes/no → auto calculates done/partial/skip |
| Meal swap | Swap upcoming meal slot with another meal from library |
| Auto-skip | Meal marked skipped if no action by end of window |
| Retroactive logging | Up to 2 hours after meal window |
| Reminders / notifications | Pre-meal, at meal time, warning, end of day summary, streak at risk |
| Notification settings | Configurable in Profile → Notifications |
| Reminder mode: fixed time | User sets exact time per meal |
| Reminder mode: interval | Start time + interval + meal count (max 6), auto-calculated |
| Interval validation | Warn if last meal falls after midnight |
| Snooze | Short delay, commitment-style, can't push past next meal |
| Daily calories + basic macros | Shown on Today screen |
| Streak system | Green (80%+) / Red (below 80%) |
| Streak preferences | Weekend skip toggle, count partial as complete toggle |
| Streak badges | Milestone badges (7, 30, 100 days) shown on profile avatar |
| History screen | Streak card, stats grid, weekly bar chart, last few days breakdown |
| Profile screen | Avatar, name, email, subscription status, settings, sign out |
| Plan editing rules | Edits affect future only, logged meals locked, snapshots for history |
| App store review prompt | After first full day, retry at 7-day streak, never ask again after 2nd dismiss |
| Data retention | 90 days after trial expiry, warning emails at day 7 and day 25 before deletion |

## May Have
| Feature | Notes |
|---|---|
| Yellow streak state | Partial day — streak survives but visually distinct |
| Per-meal reminder customization | Adjust time per meal block |
